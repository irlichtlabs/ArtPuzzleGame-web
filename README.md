# «Чья кисть?» — игра в браузере

Спокойная игра на узнавание художника: 60 картин, 12 художников, два варианта ответа и кнопка «Дальше». Без рекламы, очков, регистрации и отправки игровых результатов.

Адрес для тестирования: **https://irlichtlabs.github.io/ArtPuzzleGame-web/**

## На iPhone и iPad

1. Откройте ссылку в **Safari**. Первое открытие требует интернета.
2. Дождитесь надписи **«Готово к игре без интернета»**: сохраняются все 60 картин, примерно 17 МБ. Пока идёт загрузка, можно играть с интернетом.
3. Нажмите **«Поделиться» → «На экран Домой» → «Добавить»**.
4. Откройте игру с появившегося значка и ещё раз дождитесь готовности. Затем можно закрыть её, включить авиарежим и проверить повторный запуск.

Без установки игра тоже работает по ссылке. При неудачной загрузке появится кнопка повторной попытки. Если Safari очистит данные сайта, потребуется снова открыть игру с интернетом. Не используйте приватный режим для проверки сохранения.

Когда появится сообщение об обновлении, закройте все вкладки игры и её отдельное окно, затем откройте снова. Офлайн-возможности на конкретном устройстве нужно проверить: наличие значка само по себе не подтверждает сохранение картин.

## Что проверить

- Картина видна, обе кнопки художников читаются и реагируют после короткой защиты от случайного касания.
- Ответ раскрывается спокойно; при выборе другого художника виден пример его работы.
- «Дальше» открывает новую картину. На низком экране при длинных подписях допустима вертикальная прокрутка.
- После установки, полного закрытия и перехода в авиарежим открываются новые раунды и изображения.

При проблеме сообщите модель телефона, версию iOS, способ запуска (Safari или значок), действие и что произошло; по возможности приложите снимок экрана.
